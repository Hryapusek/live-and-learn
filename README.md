# live-and-learn

A personal repository for learning software engineering concepts through small, focused experiments.

The goal is not to collect tutorial projects. The goal is to collect things I actually understand.

## Approach

Each topic should be small enough to study in roughly 30 minutes.

A typical session consists of:

1. one new concept;
2. a small realistic example;
3. detailed analysis of how it works;
4. questions about edge cases, ownership, performance, errors, and internals;
5. a small exercise without training wheels;
6. short notes containing only the conclusions worth remembering.

Large projects are optional. They are used only when several concepts naturally need to be combined.

## Rule

> This repository is not a collection of tutorial projects. It is a collection of things I understand.
